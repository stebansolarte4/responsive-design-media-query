# Ejercicio de Responsive Design, BEM y Clip-Path

Este proyecto es una interfaz moderna desarrollada con buenas prácticas de maquetación web.

## Tecnologías y Metodologías
* **HTML5:** Marcado semántico.
* **CSS3:** Flexbox, CSS Variables, Media Queries e integración de `clip-path`.
* **Metodología BEM:** Organización limpia de clases CSS.
* **FontAwesome:** Iconos vectoriales para la interfaz.
